What is a Programmable Logic Array (PLA)?

Digital Principles & System Design (EC2201 Syllabus Unit IV: PLDs)

A Programmable Logic Array (PLA) is a Programmable Logic Device (PLD) used to implement complex combinational logic circuits in Sum of Products (SOP) form. Unlike a PROM (which has a fixed AND plane and programmable OR plane) or a PAL (which has a programmable AND plane and fixed OR plane), a PLA offers maximum flexibility because both the AND plane and the OR plane are fully programmable.

Silicon Chip Area High (2n decoder) Low / Medium Optimized (Quine-McCluskey minimizable)

PLA Internal Architecture & Signal Flow

1. Input Buffers & Inverters: Each input variable (A, B, C, D) passes through a buffer/inverter stage producing both the true rail (A) and inverted rail (A'). For 4 variables, 8 rails traverse the AND array.
2. Programmable AND Array (Product Terms): Fusible links at crosspoints connect chosen input rails to horizontal product term lines ($P_0 \dots P_k$). If a fuse is intact, that literal enters the AND gate.
3. Programmable OR Array (Sum Terms): Vertical output lines ($Y_1 \dots Y_m$) intersect the product terms with a second set of programmable fuses, performing logical OR.
4. Invert / Non-Invert Output Buffers: Optional programmable XOR gates allow active-high or active-low output polarity.

Documentation & System Specifications

1. Engineering Assumptions

  • Active-High Logic: All inputs (A, B, C, D) and outputs (Y1-Y4) assume positive logic (0 = 0V/GND, 1 = +5V/Vcc).
  • Programmable Fuses: Fusible links at the crosspoints of AND and OR arrays are intact when programmed and open when unprogrammed.
  • Zero Static Hazard: Minimization preserves necessary consensus terms to prevent dynamic glitches during single-variable transitions.

2. Syntax & Expression Format

Supported input variables are A, B, C, D. Supported operators: AND (*), OR (+), NOT ('), or direct concatenation like A'B'C.
